# QuestMind 0.1.0 内测指南（Windows）

感谢参与 QuestMind 内测。本版本面向 Windows 10/11 64 位电脑。

## 安装与启动

1. 获取 `QuestMind_0.1.0_x64-setup.exe` 后双击安装。
2. 这是尚未购买代码签名证书的内测版本，Windows 可能显示“未知发布者”。请只使用项目负责人直接提供的安装包，并先核对下方 SHA-256；来源不明时不要继续安装。
3. 启动后会先出现艾莉丝桌宠。单击桌宠身体即可打开 QuestMind 主界面；拖动身体可以移动桌宠，左下角按钮用于语音输入。
4. 本轮请统一选择“立即开始 · 体验模式”，不需要账号即可体验主要功能。体验数据只保存在当前电脑。
5. 当前云端仍有迁移未部署，暂不把账号模式、跨设备同步、Alice 日记资讯纳入本轮验收；负责人完成 `docs/BETA_RELEASE_STATUS.md` 中的阻塞项后再开放。

## 建议测试路线（约 20 分钟）

1. 体验模式进入首页，确认页面能正常切换。
2. 新建一个真实目标，检查目标分解、任务勾选和进度变化。
3. 上传一份不含隐私的 PDF、DOCX、TXT 或图片（单个文件不超过 10 MB），检查资料解析与学习内容。
4. 在艾莉丝的小屋进行两轮对话，关闭并重新打开应用，确认记录仍在。
5. 测试桌宠的单击打开、拖动、摸头与语音按钮。
6. 从系统托盘菜单测试“显示桌宠”“打开 QuestMind”和“退出”。

## 已知限制

- 安装包尚未进行商业代码签名，可能触发 Windows SmartScreen 提示。
- 体验模式的数据不会同步到其他设备，卸载或清理应用数据前请视为不可恢复。
- AI、生成式语音和实时资讯依赖网络与后端服务；失败时部分功能会降级。
- “发布任务”语音指令依赖本机已安装 Codex，仅用于已配置 Codex 的测试者。
- 请勿上传身份证件、财务、医疗、公司机密等敏感资料。
